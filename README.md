# שירים

מחברת שירים והלחנות עם אקורדים — אפליקציית web (בלי התקנה, בלי שרת), עובדת גם offline ואפשר להוסיף אותה למסך הבית.

## שימוש
פותחים את `index.html` (או מפרסמים ב-GitHub Pages).

- **כתיבה** – שם, מבצע, סולם וקאפו. בלשונית **מילים** כותבים את המילים בלבד (שורה שמתחילה ב־`#` היא כותרת מקטע). בלשונית **אקורדים** בוחרים אקורד, לוחצים על האות שמעליה הוא יופיע, וגוררים אקורד כדי להזיז אותו מעל השורה.
- **הופעה** – האקורדים מוצגים מעל המילים, עם סליידר מהירות גלילה אוטומטית (רווח = התחל/עצור), סליידר גודל גופן ובחירת גופן.
- **Aa** – גופן, גודל, מהירות, העברת טון (אפשר להטמיע בשיר), הסתרת אקורדים ומצב בהיר.
- **גיבוי / שחזור** – ייצוא וייבוא של כל השירים לקובץ JSON. השירים נשמרים בדפדפן (localStorage).
